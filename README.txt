แอประบบจัดเวรรักษาการณ์ (PWA)
อัปโหลดไฟล์ทั้งหมดในโฟลเดอร์นี้ขึ้น GitHub (ที่ระดับบนสุดของ repository)
- index.html            ตัวแอป (ไม่มีรายชื่อหรือข้อมูลจริง — ข้อมูลโหลดจาก Google Drive หลังใส่รหัสทีม)
- manifest.webmanifest  ชื่อแอป ไอคอน สี
- sw.js                 ให้แอปเปิดได้แม้เน็ตหลุด
- icon-*.png / apple-touch-icon.png / favicon.png  ไอคอน
อัปเดตแอป: อัปโหลด index.html ใหม่ทับ (Add file → Upload files → Commit)
